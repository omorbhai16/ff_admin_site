# FF I'D BUY SELL BD

HTML, CSS, JavaScript ও JSON দিয়ে তৈরি একটি Free Fire আইডি মার্কেটপ্লেস ওয়েবসাইট। অ্যাডমিন: **JAHID HASSAN**।

## লোকালি চালানোর নিয়ম

ওয়েবসাইট `fetch()` দিয়ে JSON ফাইল লোড করে। তাই `index.html` সরাসরি ডাবল-ক্লিক করে খুললে ডাটা আসবে না। অবশ্যই লোকাল সার্ভার দিয়ে চালাতে হবে।

```bash
cd FF_ID_BUY_SELL_BD
python3 -m http.server 8000
```

তারপর ব্রাউজারে খুলুন: `http://localhost:8000`

## প্রজেক্টের গঠন

- `index.html` — হোম পেজ ও আইডির লাইভ পরিসংখ্যান
- `ids.html` — আইডির তালিকা, সার্চ, ফিল্টার, সর্টিং ও ছবির গ্যালারি
- `review.html` — কাস্টমারদের রিভিউ
- `about.html` — আমাদের সম্পর্কে
- `privacy.html` — প্রাইভেসি পলিসি
- `contact.html` — Facebook, Telegram ও WhatsApp যোগাযোগের লিংক
- `assets/css/style.css` — পুরো সাইটের স্টাইল
- `assets/js/app.js` — হেডার/ফুটার, লোগো অ্যানিমেশন, আইডি দেখানো, ফিল্টার ও কন্টাক্ট
- `data/ids.json` — আইডির তালিকা (হোম পেজের পরিসংখ্যানও এখান থেকে হিসাব হয়)
- `data/reviews.json` — কাস্টমার রিভিউ
- `data/config.json` — সাইটের নাম, অ্যাডমিন ও যোগাযোগের লিংক
- `data/navigation.json` — নেভিগেশন মেনু
- `logo/logo_1.jpg` থেকে `logo/logo_13.jpg` — ভেসে পড়া লোগো ছবি
- `image/01/`, `image/02/`, `image/03/`, `image/04/` … — প্রতিটি আইডির স্ক্রিনশটের আলাদা ফোল্ডার

## নতুন Free Fire আইডি যোগ করার নিয়ম

১. `image/` ফোল্ডারের ভেতরে নতুন নম্বর দেওয়া ফোল্ডার বানান, যেমন `image/05/`।

২. ওই আইডির স্ক্রিনশটগুলো ফোল্ডারে রাখুন, যেমন `image/05/01.jpg`, `image/05/02.jpg`।

৩. `data/ids.json` ফাইল খুলুন। ফাইলটি একটি **তালিকা (`[ ... ]`)**। নতুন আইডির `{ ... }` ব্লকটি শেষ আইডির পরে বসান। **দুটি ব্লকের মাঝখানে কমা `,` দিতে হবে, কিন্তু শেষ ব্লকের পরে কমা দেওয়া যাবে না।**

৪. বিক্রির জন্য থাকলে `"status": "available"` এবং বিক্রি হয়ে গেলে `"status": "sold"` লিখুন।

৫. প্রতিটি আইডির ছবি নিজস্ব নম্বর-ফোল্ডারে রাখুন। **কখনো পাসওয়ার্ড, রিকভারি কোড বা লগইনের কোনো তথ্য প্রকাশ করবেন না।**

### আইডির উদাহরণ

```json
[
  {
    "id": "FF-004",
    "name": "Free Fire Premium Account",
    "status": "available",
    "price": 3500,
    "uid": "123456789",
    "level": 65,
    "likes": 12000,
    "primeLevel": "Prime 4",
    "images": ["image/04/01.jpg", "image/04/02.jpg"],
    "description": "Premium Free Fire account with valuable items.",
    "createdAt": "2026-10-29"
  },
  {
    "id": "05",
    "name": "Free Fire Account #05",
    "status": "available",
    "price": 2000,
    "uid": "100000005",
    "level": 60,
    "likes": 8000,
    "primeLevel": "Prime 3",
    "images": ["image/05/01.jpg"],
    "description": "বিবরণ এখানে লিখুন।",
    "createdAt": "2026-10-30"
  }
]
```

### ফিল্ডগুলোর অর্থ

| ফিল্ড | অর্থ |
|---|---|
| `id` | আইডির ইউনিক কোড (প্রতিটির আলাদা হতে হবে) |
| `name` | আইডির নাম/শিরোনাম (পুরোনো `title` লিখলেও চলবে) |
| `status` | `available` (আছে) অথবা `sold` (বিক্রি হয়েছে) |
| `price` | দাম (টাকায়, শুধু সংখ্যা) |
| `uid` | Free Fire UID |
| `level` | লেভেল (সংখ্যা) |
| `likes` | লাইক সংখ্যা (পুরোনো `like` লিখলেও চলবে) |
| `primeLevel` | প্রাইম লেভেল, যেমন `"Prime 4"` (শুধু `4` লিখলেও চলবে) |
| `images` | ছবির পাথের তালিকা |
| `description` | বিবরণ |
| `createdAt` | যোগ করার তারিখ (`YYYY-MM-DD`)। এটা দিয়েই "নতুন আগে" সাজানো হয় |

> **টিপস:** `ids.json` সরাসরি তালিকা `[ ... ]` অথবা `{ "ids": [ ... ] }` — দুই রকম ফরম্যাটই এখন কাজ করে।

## আইডি ওয়েবসাইটে না দেখালে যা যা চেক করবেন

১. **ফাইল সরাসরি খুলবেন না।** `python3 -m http.server 8000` দিয়ে চালান (বা হোস্টিংয়ে আপলোড করুন)।

২. **JSON-এ সিনট্যাক্স ভুল আছে কিনা দেখুন।** সবচেয়ে সাধারণ ভুল:
   - দুই আইডির মাঝে কমা `,` ভুলে যাওয়া
   - শেষ আইডির পরে বাড়তি কমা দেওয়া
   - `"` (ডাবল কোটেশন) এর বদলে `'` ব্যবহার করা
   - `{ }` বা `[ ]` বন্ধ করতে ভুলে যাওয়া

   [jsonlint.com](https://jsonlint.com) এ ফাইলের লেখা পেস্ট করলে ভুল ধরা পড়বে।

৩. **ব্রাউজারে হার্ড রিফ্রেশ করুন** (`Ctrl + Shift + R`)। কোড এখন `no-store` দিয়ে ডাটা আনে, তবুও হোস্টিংয়ে CDN ক্যাশ থাকলে নতুন ডাটা আসতে একটু সময় লাগতে পারে।

৪. **ছবি না দেখালে** `images`-এ লেখা পাথ ও ফাইলের নাম হুবহু মিলতে হবে (বড়/ছোট হাতের অক্ষরসহ, যেমন `1.jpg` আর `01.jpg` আলাদা)। পাথ ঠিক আছে কিনা এবং ছবির ফাইল ওই ফোল্ডারে আছে কিনা দেখুন। ছবি না পেলে সাইট একটি ডিফল্ট ছবি দেখাবে, কিন্তু আইডি ঠিকই দেখাবে।

৫. কিছুতেই না হলে ব্রাউজারে `F12` চেপে **Console** ট্যাবের লাল এরর দেখুন।

## যোগাযোগের তথ্য আপডেট

Facebook, Telegram ও WhatsApp এর তথ্য `data/config.json` ফাইলে আছে। বর্তমান লিংক ও নম্বর আগে থেকেই সেট করা।
